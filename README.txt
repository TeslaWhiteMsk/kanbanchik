Kanbanchik v1.0
================
Канбан-доска на Python 2.7 + Tkinter
Три колонки: Надо | Делаю | Готово

Запуск
------
  1. Дважды кликните Kanbanchik.bat
  2. Или выполните в командной строке: python kanbanchik.py

Управление
----------
  +                          Добавить карточку в колонку
   Двойной клик по карточке   Редактировать карточку
   Правый клик по карточке    Контекстное меню (редактировать / удалить)
   Перетаскивание             Переместить карточку между колонками
   Перетаскивание разделителя Изменить ширину колонок
   Двойной клик разделителя   Сбросить ширину колонок (поровну)
   Ctrl+N                     Новая доска
  Ctrl+O                     Открыть доску из файла
  Ctrl+S                     Сохранить доску в файл
  Esc                        Отменить перетаскивание

Файлы
-----
  По умолчанию доска сохраняется в board.json в папке программы.
  При запуске файл board.json загружается автоматически, если он существует.

Требования
----------
  Python 2.7 (32-бит)
  Стандартная библиотека (дополнительные пакеты не требуются)
